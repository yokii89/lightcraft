# 扩展两级导航 · 地理位置分类 · 设计

- 状态：已实现（真实地名数据的端到端待装有 GeoNames 数据集与带 GPS 照片的机器验证）
- 日期：2026-11-11
- 范围：`lightcraft-extension`（`extension/`）；原生代码只允许追加式注册缝
- 相关：[`00-本地模型自动关键词设计.md`](00-本地模型自动关键词设计.md)（第一个功能）、
  [`02-地理分类地图视图设计.md`](02-地理分类地图视图设计.md)（评审阶段的地图层）

## 1. 目标

扩展面板从「每个功能一个页签」改为**两级页面**：

- **1级页面（hub）**：列出本扩展的功能——「自动关键字」「按地理位置分类」，每个一张卡片；
- **2级页面**：点进卡片才是具体功能。面包屑行（`‹ 扩展`）回到 1级。

这样后续加功能只改扩展 crate 的 `features()` 列表，原生不再感知每个具体功能。

## 2. 结构

```
extension/src/
  lib.rs           pages() 只注册一个 ExtensionPage：hub（id "extensions"）
  hub.rs           1级列表 + 面包屑 + 功能分派；导航状态 static OPEN（面板关闭后保持）
  scope.rs         两页共用：范围枚举、计数（图库数按 revision 缓存）、分段选择器
  ui.rs            两页共用：卡片/小节/字段行/提示/警告/trn 占位翻译/秒数格式
  auto_keywords/   功能一（原样，成为 2级页面；状态机不变）
  geo_classify.rs  功能二（本设计新增）
```

- 旧的 `example` 模板页移除（hub 取代了它的示范作用；git 历史保留）。
- 侧栏「扩展」区块只剩一行「扩展」，点开是 1级页面——与用户模型一致。
- 导航状态与各功能状态一样放 `static`，面板关闭再打开仍停留在原处。

## 3. 地理位置分类（功能二）

### 3.1 用户流程

1. 2级页面显示**地名数据**卡片：`metadata.placeNamesStatus` 的结果——已下载
   （大小 + GeoNames CC-BY 4.0 出处）或未下载（**下载地名数据**按钮，调用
   `metadata.downloadPlaceNames`，后台 ~3 MB；下载中每 500 ms 轮询状态）。
2. 选择范围（选中/视图/图库，与功能一共用的分段控件）、父级关键字（默认 `地点`）。
3. **开始分类**：对范围内每张带 GPS 的照片，用 GeoNames 地名库离线反查「国家 / 城市」，
   生成评审列表；无 GPS 的与未匹配到的照片单独计数、不参与写入。
4. 评审页按**最终关键字路径**分组（`父级|国家|城市`）：每组勾选、可展开逐张勾选；
   计数实时更新；**写入 N 张照片**一次提交（一个 `Op::Batch`，一个撤销步骤）。
5. 完成页：写入数、关键字数、撤销这一批、继续分类。

### 3.2 为什么不走 `metadata.reverseGeocode` 命令

- 该命令的 enabled 检查要求**当前有选择**（`has_selection`），而「整个图库 / 当前视图」
  范围常常没有选择；
- 它写的是位置**元数据字段**（City/State/Country），本功能写的是**关键字**；
- 因此扩展直接使用公共 crate `lightcraft_geocode`（原生命令也是基于它）：自己枚举范围、
  读 `meta.gps`、`GeoNames::load`（按 (路径, 大小, mtime) 缓存于页面状态，与原生
  `PlaceNames` 缓存同一策略）、`reverse()` 出 `国家/城市/距离`。数据集的下载与状态
  仍走原生命令，两处共享同一份 `<设置目录>/geonames`。

### 3.3 边界与约束

- 地名库列出 1.5 万人以上的城镇（cities15000）：小地方的照片直接归到**国家**一层
  （`父级|国家`）；照片到地点的距离在评审里按 km 显示。
- 地名数据（CC-BY 4.0）在页面上始终显示出处字符串。
- 查找完全离线：位置不出本机（原生设计不变）。
- 首次 `GeoNames::load` 同步解析 ~3 MB（一次约几百毫秒），之后走缓存；v1 不做
  后台化，与原生元数据面板行为一致。
- v1 不持久化设置（唯一可改的父级关键字为内存态）；照片逐张勾选在有数百张照片的
  大组里会较长，v1 接受（组级勾选已覆盖主要场景）。

## 4. 测试

- 路径与分组：父级为空、层级清洗、按路径分组且有序、空城市归国家。
- 写入：with_demo + 合成查找结果——一个批次一个撤销步骤、`note_recent`、撤销恢复；
  已有关键字（大小写不同）去重；组级/照片级排除；无新关键字不提交。
- 页面：headless 渲染——数据集状态卡（未下载 + 出处字符串）、评审计数随勾选变化、
  回到 1级后状态清理但保留父级关键字。
- hub：只注册一个页面；两功能卡片注册自动化 id；1级↔2级渲染（面包屑、返回钮）。

## 5. 验收标准

- 侧栏「扩展」→ 1级列表 → 点「自动关键字」进入原功能且一切照旧；
- 「按地理位置分类」：装好地名数据集与带 GPS 的照片后，评审分组、写入
  `父级|国家|城市`、整批一个撤销步骤；
- `cargo fmt --all -- --check`、`cargo test -p lightcraft-extension`、
  `cargo clippy -p lightcraft-extension --all-targets -- -D warnings` 通过；
- 除 `crates/ui-egui/locales/zh-hans.json` 数据条目外，没有原生文件改动。
