# 文搜图页面整理

- 日期：2026-11-14
- 范围：文搜图页面的布局、信息层级和交互；沿用已有检索与缓存实现。
- 参照：AI 关键字页的卡片与固定底部动作栏。

## 页面结构

1. 扩展导航提供标题，正文保留一个搜索输入卡片，取消重复标题和常驻技术说明。
2. 搜索按钮固定在底部，后台任务执行时替换为停止按钮；进度沿用活动任务列表。
3. 「高级」默认收起，包含索引数量、更新索引、下载模型和匹配阈值。非零更新统计只在其中显示。
4. 搜索成功后显示结果卡片。每行只保留缩略图、文件名和一行描述，长文本省略，悬停查看详情与相似度。
5. 无匹配结果时显示简短提示；初始状态不显示零结果和零耗时。输入改变时清除旧结果和提示。

## 视觉与交互

复用 `split_page`、`card`、`card_head`、`action_bar` 与全宽按钮，统一页边距 12、卡内边距 11、
卡距 10、动作栏高度 66。高级开关与 AI 关键字保持相同的箭头、幽灵按钮和默认折叠行为。

保留 Enter 搜索、点击文件名选中照片、在图库中显示结果、停止任务等操作和已有自动化 id。
新增 `semantic:advanced`。面板过矮无法固定动作栏时，按钮随内容滚动，保持可达。
