规格卡

入口
「按地理位置分类」评审阶段：地图即主视图，撑满扩展面板；可整卡收起。
范围
v1 只画中国：国家为中国的分组上图；中国以外、未匹配、无 GPS 不上图（汇总行说明）。
投影
等经纬线性投影（x 按 cos 35° 压缩），正视图朝北、不旋转；无瓦片、无网络、无第三方地图库。
缩放
滚轮（以光标为锚）+ 右上 +/−/复位 按钮 + 双击放大 + 拖动平移；spanLon 62°（全国）→ 1.2°（街区），平移限制在中国范围附近。
两级呈现
spanLon > 9°：地点气泡（r=2.35·√照片数，计数在泡内）；≤ 9°：拆成逐张照片缩略图散在拍摄点周围，随放大变大（34→54 px），每地最多几十张、以「+N」计其余。
查看
点击缩略图 → 该照片在中间栏大图展示（文件名 · 地点 · 距离 · 将写入的关键字路径）；「‹ 返回网格」回到图库网格。
地点卡
点击气泡弹出地点卡（代替列表）：纳入写入勾选、「聚焦」跳转、关闭；点空白处关闭。
边界
原型为手绘简化轮廓 + 海南/台湾 + 南海诸岛 inset（本仓库原创矢量）；正式实现必须换标准中国边界数据（如自然资源部标准地图服务），示意边界不得随产品发布。
性能
底图 SVG（陆地/经纬网）世界坐标一次生成，缩放/平移只改 viewBox；气泡/缩略图按经纬度重投影定位，rAF 节流。egui 实现同理：Painter 重绘 ≤ 16 ms。
落点
全部在 extension/src/geo_classify.rs（新增 map 模块）；不改原生代码。

交互

  • 评审页顶部汇总「待写入 X 张 · Y 个地点」+ 全部接受/丢弃；地图撑满其余高度；底部「写入 N 张照片」。
  • 气泡：悬停 tooltip「地名 · N 张」；点击弹出地点卡——勾选「纳入写入」、「聚焦」放大到该地。
  • 放大越过阈值（spanLon ≤ 9°）气泡拆成缩略图；继续放大缩略图变大、可逐张点击。
  • 点击缩略图：中间栏切换为单图查看（loupe），缩略图高亮；「返回网格」还原。写入勾选状态不受影响。
  • 密集城市（广深、成渝）国家级视角少量重叠：按数量降序绘制，小泡在上；按屏幕距离聚合留作改进。

设计决策

  • 地图是主视图（2026-11-11 二稿，按反馈去掉地图下方的城市列表）：评审数据完全落在地图上，每地操作走气泡弹出卡。
  • 可交互正视图：滚轮锚点缩放 + 拖动平移 + 双击放大，替代固定预置档为主、chips 仅作快捷方式。
  • 缩略图即照片定位：照片 GPS 抖动散布在地点周围是示意——真实实现按每张照片自己的经纬度落点。
  • 无瓦片：离线、无网络请求；边界数据编译进扩展，需记录出处。
  • 南海诸岛：右下角 inset 固定显示，遵守标准地图画法。
