- 状态：已实现（v1：气泡/缩略图两级、缩放平移、地点卡、缩略图→详情；标准边界数据替换与逐张排除留待后续）
- 日期：2026-11-11
- 范围：`lightcraft-extension`（`geo_classify/map.rs` + 评审页重构）；原生代码只动了 `zh-hans.json` 数据条目
- 原型：[`ui-design/geo-map.html`](ui-design/geo-map.html)（独立打开即可交互）

## 1. 目标

评审阶段**以一张可交互的中国地图为主视图**：照片按反查出的地点散在地图上，
气泡大小 ∝ 照片数；放大后出现**逐张照片缩略图**，点击缩略图该照片在**中间栏**大图展示。
用户决策（2026-11-11）：**v1 只做中国区域，不做全球地图**；地图下方不设城市列表
（二稿按反馈移除，每地操作走气泡弹出卡）。

## 2. 布局

```
评审页（地图撑满扩展面板其余高度，可整卡收起）
├─ 汇总行  待写入 X 张 · Y 个地点（+ 中国以外/未匹配/无 GPS 计数） [全部接受] [全部丢弃]
├─ 地图卡片（主视图）
│   ├─ 左上 chips：全国 / 华东 / 珠三角 / 川西（快捷缩放）
│   ├─ 右上按钮：放大 / 缩小 / 复位
│   ├─ 地图（气泡 ⇄ 缩略图两级呈现）+ 地点弹出卡 + tooltip
│   └─ 图例行 + 边界示意标注 + 南海诸岛 inset（区域级以上显示）
└─ 写入 N 张照片
```

## 3. 地图设计

- **投影**：等经纬线性投影，x 按 cos 35° 压缩，正视图朝北、不旋转；无瓦片、无网络请求、
  无第三方地图库——与「位置不出本机」一致。
- **缩放/平移**：滚轮以光标为锚缩放、拖动平移、双击放大、右上 +/−/复位 按钮；
  spanLon 62°（全国）→ 1.2°（街区），平移限制在中国范围附近。chips 仅作快捷方式。
- **两级呈现**：spanLon > 9° 显示地点气泡（r = clamp(2.35·√照片数, 8, 30)，大泡先画小泡在上，
  计数在泡内，spanLon ≤ 18° 显示地名标注）；≤ 9° 拆成**逐张照片缩略图**：按拍摄点周围散布、
  随放大变大（34→54 px）、每地最多几十张并以「+N 张」计其余。
- **照片落点**：原型按地点中心示意散布；真实实现按每张照片**自己的 GPS** 落点，
  缩略图即照片的真实位置。
- **边界**：手绘简化中国轮廓 + 海南、台湾单独成面 + 南海诸岛 inset（虚线示意 + 岛屿点 +
  标注，区域级以上显示，放大后隐藏避免遮挡）。轮廓是本仓库原创示意矢量。
  ⚠️ **正式实现必须换标准中国边界数据**（如自然资源部标准地图服务），记录出处与许可；
  示意边界不得随产品发布，图中「边界为示意」标注在换数据后移除。
- **中国以外**：不上图（东京、河内等只在汇总行出现）。未来做全球地图时按国家聚合再下钻。

## 4. 交互

- 悬停气泡/缩略图：tooltip（「地名 · N 张」/「文件名 · 距地名 km」）。
- 点击气泡 → **地点弹出卡**（代替列表）：纳入写入勾选、「聚焦」（放大到该地并拆点）、关闭；
  点空白处/缩放平移后关闭。
- 点击缩略图 → 该照片在**中间栏大图展示**（loupe：文件名 · 地点 · 距离 · 将写入的关键字路径），
  缩略图高亮；「‹ 返回网格」回到图库网格。写入勾选状态不受影响。
- 勾选（地点卡）实时改变「待写入」计数与写入按钮。

## 5. 边界情况

- 密集城市（广深、成渝、康定/稻城）国家级视角少量重叠：按数量降序绘制 + 白描边分隔，v1 接受；
  **按屏幕距离聚合**（点击聚合泡列出所含地点）留作实现时的改进。
- 缩略图之间的重叠：散布半径随缩略图尺寸放大，v1 接受少量叠压（真实 GPS 落点天然分散）。
- 视图外地点正常渲染（被裁剪）；面板收起或宽度变化时重算一次布局。

## 6. 性能

- 底图 SVG（陆地/经纬网）世界坐标一次生成，缩放/平移只改 viewBox；气泡/缩略图按经纬度
  重投影定位，rAF 节流。egui 实现同理：Painter 重绘只在视图/勾选变化时发生，≤ 16 ms。

## 7. 文案与 i18n

新增文案走 `i18n::tr`，英文为源语言，简体中文写入 `zh-hans.json`
（完整审计表见原型下方）：Map（地图）、缩放快捷 chips、Zoom in/out / Reset view（放大/缩小/复位）、
Include in write（纳入写入）、Focus（聚焦）、Back to grid（返回网格）、
Bubble size = photo count …（图例）、Outside China …（汇总行）、South China Sea Islands（南海诸岛）、
+{n} more（+{n} 张）等。

## 8. 测试

- headless 渲染：评审页地图卡片撑满（自动化 id `geo:map`）；气泡数 = 中国分组数；
  点击气泡弹出地点卡；「纳入写入」勾选后计数变化；「聚焦」后拆为缩略图；
  点击缩略图后中间栏展示该照片、缩略图高亮；「返回网格」还原；
  收起地图不破坏勾选状态。
- 缩放/平移：滚轮与按钮改变 spanLon 且锚点正确；平移限制生效；缩略图阈值切换正确。
- 边界：全部分组都在中国以外时地图显示空态提示而非空白画布。

## 9. 验收标准

- 评审页地图为主视图：缩放/平移/双击/chips/按钮交互如上，气泡 ⇄ 缩略图两级呈现正确；
- 点击缩略图中间栏展示照片；地点弹出卡可排除/聚焦；
- `cargo fmt --all -- --check`、`cargo test -p lightcraft-extension`、
  `cargo clippy -p lightcraft-extension --all-targets -- -D warnings` 通过；
- 除 `crates/ui-egui/locales/zh-hans.json` 数据条目外，没有原生文件改动。
