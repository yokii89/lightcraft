- 状态：已实现（v1：气泡/缩略图两级、缩放平移、地点卡、缩略图→详情；v1.1：高德在线底图 + GCJ-02 + 离线回退；标准边界数据替换与逐张排除留待后续）

- 范围：`lightcraft-extension`（`tiles.rs` + `geo_classify/map.rs` + 评审页文案）；原生代码只动了 `zh-hans.json` 数据条目

## 1. 目标

评审阶段**以一张可交互的中国地图为主视图**：照片按反查出的地点散在地图上，
气泡大小 ∝ 照片数；放大后出现**逐张照片缩略图**，点击缩略图该照片在**中间栏**大图展示。
用户决策（2026-11-11）：**v1 只做中国区域，不做全球地图**；地图下方不设城市列表
（二稿按反馈移除，每地操作走气泡弹出卡）。

## 2. 布局

```
评审页（地图撑满扩展面板其余高度，可整卡收起）
├─ 汇总行  待写入 X 张 · Y 个地点（+ 中国以外/未匹配/无 GPS 计数） [全部接受] [全部丢弃]
├─ 地图卡片（主视图）
│   ├─ 左上 chips：全国 / 华东 / 珠三角 / 川西（快捷缩放）
│   ├─ 右上按钮：放大 / 缩小 / 复位
│   ├─ 地图（高德在线瓦片底图 + 气泡 ⇄ 缩略图两级呈现）+ 地点弹出卡 + tooltip
│   ├─ 左下：在线底图开关（关闭即离线示意底图）
│   ├─ 右下：© 高德地图 署名（瓦片显示时）；回退时改为南海诸岛 inset
│   └─ 图例行 + 回退时的边界示意标注
└─ 写入 N 张照片
```

## 3. 地图设计

### 3.1 底图

- **来源**：高德地图（AMap）256 px 栅格瓦片，`style=7` 中文注记道路底图，
  四个 `webrd0{1-4}` 子域按瓦片分散请求；**不使用高德 JS SDK**（本应用是纯 Rust 原生，
  没有 webview），由 `extension/src/tiles.rs` 直接请求栅格端点。
- **投影**：Web Mercator；瓦片按标准 `z/x/y` 金字塔排列，级别由「视口宽度 ÷ spanLon」
  和屏幕 DPI 共同决定（z3–18，HiDPI 自动加一级）。x 轴为经度，y 轴为墨卡托纬度。
- **坐标基准**：高德瓦片是 GCJ-02（火星坐标），照片 EXIF 是 WGS-84。
  `wgs_to_gcj` 在投影前偏移、`gcj_to_wgs` 把屏幕点换回 WGS-84，落点与街道对齐
  （迭代逆变换，误差 ≪ 1 m）。中国境外不偏移。
- **缩放/平移**：滚轮以光标为锚缩放、拖动平移、双击放大、右上 +/−/复位 按钮；
  spanLon 62°（全国）→ 0.02°（街区，对应瓦片 z16），平移限制在中国范围附近。
  锚点在墨卡托空间精确保持。缩放级别随 spanLon 变化，瓦片按级别切换。chips 仅作快捷方式。
- **加载**：4 个后台工作线程，最多 12 个在途请求；UI 线程只做纹理上传（每帧最多 8 张）。
  完成的瓦片以 RGBA 纹理缓存（上限 192 张，最近最少绘制者先淘汰）；失败的瓦片 30 s 后重试。
  **瓦片不写磁盘**，退出即清空（避免缓存条款，见 §3.3）。
- **回退**：在线开关关闭、瓦片尚未到达或网络不可用时，地图继续绘制原有的示意中国轮廓
  （手绘矢量，墨卡托投影）+ 经纬网 + 南海诸岛 inset，绝不出现空白画布。
  瓦片到达后覆盖示意底图；AMap 瓦片自带标准边界与南海诸岛 inset，此时不再画示意图层。

### 3.2 两级呈现与落点

- spanLon > 9° 显示地点气泡（r = clamp(2.35·√照片数, 8, 30)，大泡先画小泡在上，
  计数在泡内，spanLon ≤ 18° 显示地名标注）；≤ 9° 拆成**逐张照片缩略图**：
  按拍摄点周围散布、随放大变大（34→54 px）、每地最多几十张并以「+N 张」计其余。
- 照片按**自己的 GPS** 落点；坐标先做 GCJ-02 偏移再投影，缩略图即照片在底图上的真实位置。
- **边界**：回退示意图为手绘简化中国轮廓 + 海南、台湾单独成面 + 南海诸岛 inset；
  在线底图显示时以 AMap 的标准边界为准。
  ⚠️ 回退轮廓是本仓库原创示意矢量，不随产品替代正式边界数据。
- **中国以外**：不上图（东京、河内等只在汇总行出现）。未来做全球地图时按国家聚合再下钻。

### 3.3 许可与合规（维护者决定，2026-11-12）

- 参考项目 `extension/参考/map-main` 的地图是高德 JS API 2.0 的默认栅格瓦片；
  `extension/参考/picmap-main` 也直接请求 `webrd0x.is.autonavi.com` 的栅格 URL。
- 高德开放平台服务协议 7.3 与《高德服务条款》6.7.2/6.7.4 禁止绕过官方 SDK
  抓取、存储、缓存、下载瓦片，也禁止用第三方工具接入。本实现属于**违约直连**：
  维护者在明确知悉该风险后决定采用（2026-11-12），风险由项目承担。
- 降低影响的措施：地图右下角始终显示「© 高德地图 (AutoNavi)」署名；
  提供**在线底图开关**（关闭后完全离线）；瓦片只在内存中驻留，不写磁盘；
  请求带明确的 `User-Agent`，并发受限（4 线程 / 12 在途）。
- 若日后合规要求变化，底图实现集中在 `extension/src/tiles.rs`，
  换源（天地图/OSM/自建）只需替换 URL 与坐标基准，地图相机与交互不变。

## 4. 交互

- 悬停气泡/缩略图：tooltip（「地名 · N 张」/「文件名 · 距地名 km」）。
- 点击气泡 → **地点弹出卡**（代替列表）：纳入写入勾选、「聚焦」（放大到该地并拆点）、关闭；
  点空白处/缩放平移后关闭。
- 点击缩略图 → 该照片在**中间栏大图展示**（loupe：文件名 · 地点 · 距离 · 将写入的关键字路径），
  缩略图高亮；「‹ 返回网格」回到图库网格。写入勾选状态不受影响。
- 勾选（地点卡）实时改变「待写入」计数与写入按钮。
- 左下「在线底图」开关：关闭后不发任何瓦片请求，立即回到离线示意底图；再打开恢复在线底图。

## 5. 边界情况

- 密集城市（广深、成渝、康定/稻城）国家级视角少量重叠：按数量降序绘制 + 白描边分隔，v1 接受；
  **按屏幕距离聚合**（点击聚合泡列出所含地点）留作实现时的改进。
- 缩略图之间的重叠：散布半径随缩略图尺寸放大，v1 接受少量叠压（真实 GPS 落点天然分散）。
- 视图外地点正常渲染（被裁剪）；面板收起或宽度变化时重算一次布局。
- 网络：瓦片请求失败只影响该瓦片（30 s 后重试），地图继续显示示意底图；
  面板关闭后完成的瓦片仍会进入内存缓存，下次进入不重复下载。
- 隐私：在线底图开启时，**正在浏览的区域**会发送给高德服务器（与地名查询的离线承诺分开）；
  开关关闭后完全离线。设计记录见 §3.3。

## 6. 性能

- 底图与气泡/缩略图都按经纬度经 GCJ-02 偏移后重投影；Painter 重绘只在视图/勾选变化时发生。
- 瓦片：4 个后台线程拉取并解码（单张上限 4 MiB / 1024²），UI 线程每帧最多上传 8 张纹理；
  纹理上限 192 张（LRU），失败的瓦片退避重试。UI 线程从不等待网络。
- 解码后的瓦片只在内存驻留，不写磁盘。

## 7. 文案与 i18n

新增文案走 `i18n::tr`，英文为源语言，简体中文写入 `zh-hans.json`
（完整审计表见原型下方）。本次新增：
Online map（在线底图）、Loads map tiles from the AMap servers; the viewed area is sent to them.
（从高德服务器加载地图瓦片；浏览区域会发送给高德。）；地名数据提示改为说明「在线底图单独加载」。
署名 `© 高德地图 (AutoNavi)` 是常量，不翻译。

## 8. 测试

- headless 渲染：评审页地图卡片撑满（自动化 id `geo:map`）；气泡数 = 中国分组数；
  点击气泡弹出地点卡；「纳入写入」勾选后计数变化；「聚焦」后拆为缩略图；
  点击缩略图后中间栏展示该照片、缩略图高亮；「返回网格」还原；
  收起地图不破坏勾选状态。
- 缩放/平移：滚轮与按钮改变 spanLon 且锚点正确；平移限制生效；缩略图阈值切换正确；
  Web Mercator 投影与 GCJ-02 正/逆变换往返正确。
- 瓦片：级别随 spanLon/DPI 变化且在 z3–18 内；URL 指向 `webrd0x.is.autonavi.com`；
  恶意/空/超大瓦片解码返回错误而不 panic；缓存中放入一张瓦片后 headless 渲染出现纹理
  与「© 高德地图」署名、示意标注消失。`cargo test` 下网络请求恒关闭，测试不依赖外网。
- 快照限制：`ui.screenshot {headless:true}` 与 `lightcraft-cli snapshot` 用影子 egui 上下文，
  只带渲染器的照片纹理；扩展用 `ctx.load_texture` 上传的瓦片在快照里不可见，底图区域空白
  （气泡、开关、署名仍在）。底图目测用窗口截图；贴图逻辑由注入纹理的 headless 用例覆盖。
- 边界：全部分组都在中国以外时地图显示空态提示而非空白画布。

## 9. 验收标准

- 评审页地图为主视图：缩放/平移/双击/chips/按钮交互如上，气泡 ⇄ 缩略图两级呈现正确；
- 在线底图为高德瓦片，落点经 GCJ-02 校正在街道级对齐；右下署名、左下开关可见；
- 关闭开关或断网时回退示意底图且交互不退化；
- 点击缩略图中间栏展示照片；地点弹出卡可排除/聚焦；
- `cargo fmt --all -- --check`、`cargo test -p lightcraft-extension`、
  `cargo clippy -p lightcraft-extension --all-targets -- -D warnings` 通过；
- 除 `crates/ui-egui/locales/zh-hans.json` 数据条目外，没有原生文件改动。

## 10. GPX 轨迹叠加与照片匹配

- 地图库可添加最多 4 个 `.gpx` 文件。选取路径保存在当前图库的 `geo-classify.json`；文件内容不复制到图库。
- 文件选择和解析不阻塞 UI。每个文件最多 64 MiB、1,000,000 个有效定时点；解析期间显示活动行。缺失或无效文件从保存列表中移除并显示错误。
- GPX 1.0/1.1 使用共享 `lightcraft_meta::parse_gpx`。只画定时轨迹点，按 `trkseg` 分段绘制，段间丢点不连线；跨 ±180° 经线的点对也不画长直线。地图每条路线最多绘制 20,000 个抽样点。
- 「聚焦轨迹」按路线范围调整地图相机；地图相机允许全球经纬度，默认视角仍为中国。
- 「匹配所选照片」调用现有 `photo.tagFromTracklog` UI 流程：照片按拍摄时间与 GPX UTC 时间插值或取时间窗内最近点，已有 GPS 默认保留，时区缺失时仍询问相机时区，写入沿用单步撤销。可先从地图地点卡选择地点照片。
- 匹配结果写入照片 GPS 后，地图相册的现有增量同步会更新位置与地点分类。轨迹层只用于显示与匹配，不替代相册地理分类。
